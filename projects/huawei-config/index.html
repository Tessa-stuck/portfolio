Huawei ONT Config Generator

Buat ONT Huawei (HG8145V5) yang nggak ada menu Add WAN. Isi form → generate file config → import ke ONT. Support PPPoE, Bridge, Static, TR-069 + VLAN & port/SSID binding. Diproses 100% di browser.

Hasil (XML)
⚠️ Catatan: tes dulu file-nya di ONT sebelum dipakai serius, dan backup config lama kamu. Setiap tipe/firmware bisa beda dikit.
Cara pakai:
1. Import file ini di ONT: System Management → Configuration File → Update/Import.
2. Setelah restart, login akun Support (password default vendor).
3. Lihat daftar WAN di 192.168.100.1/html/bbsp/wan/wan.asp.
4. SSID5–SSID8 = SSID 5GHz. Binding kosong = nggak di-bind ke port/SSID.
